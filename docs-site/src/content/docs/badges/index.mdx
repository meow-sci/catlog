Merit badges are catlog's planned once-only recognitions for things that happened in your recorded
history. A badge will not be a score or a level, and earning one will not make a leaderboard value
larger.

<Aside type="note" title="The foundation is here; the badges are not">
  catlog can now store this kind of recognition, knows the catalogue below, and has the once-only
  writing machinery ready. No badge rules are active yet, so none of these can be earned and no
  awards or player badge pages are exposed. Those arrive in later work.
</Aside>

## The planned catalogue

Thirty-five badges have fixed names. Three more are families: the place name becomes part of the
badge, using the same names your game reports. The groups only organise the catalogue. A tier is a
ladder label, not a level that replaces anything below it.

The three exploration families are **Reached _&lt;world&gt;_** — “You reached _&lt;world&gt;_.”,
**Orbited _&lt;world&gt;_** — “You made orbit around _&lt;world&gt;_.”, and **Landed on
_&lt;world&gt;_** — “You landed on _&lt;world&gt;_.” They use the world's reported name and have no built-in
list of places. A game update or a modified celestial system can therefore supply its own names. A
name that cannot form a safe page address gets no family badge, but still counts towards the fixed
visit totals.

Fixed badges always belong in the catalogue. By default, a place-specific family badge will be
published only after two players have it — the same configurable threshold as a place-specific
leaderboard. That prevents one person's private system name from becoming a public catalogue entry,
without teaching catlog a list of permitted worlds.

## Two views of the same achievement

The model keeps lifetime and per-save recognition separate. A qualifying achievement can be
remembered once for the player and independently once for the save in which it happened. A new save
starts with no per-save badges of its own; it does not erase a lifetime recognition that still
qualifies.

For a lifetime recognition, catlog also remembers which save and celestial system first produced it
in the current result. A per-save recognition already belongs to that save and keeps its system
alongside it. The time attached to either comes from when the catlog server received the event; a
career-clock time is kept only when the event had one.

## “Once” means once in the current result

Awards will keep the first qualifying moment while one set of derived data is being built. Like the
leaderboards, they are rebuilt from the recorded event history rather than kept as permanent claims.
A rebuild may remove a recognition when the current rules or final flight facts no longer award it,
and a future rule may discover one in older history.

The writer is already prepared for several qualifying moments arriving together: the earliest one
keeps all of its matching time, save, system and detail, and a later duplicate changes nothing. One
qualifying moment can be kept independently for your lifetime and for that save. Nothing invokes
that writer yet; the planned catalogue above remains unearnable for now.

That also keeps moderation complete. Withheld history produces no badges after a rebuild; restored
history can produce them again in its original order; deleted history cannot.
