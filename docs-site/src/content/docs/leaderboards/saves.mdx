A save is one KSA game, played over as many sittings as you like. Close the game,
come back tomorrow and load the same save, and catlog still treats it as the same
one. Start a new game and it is a new save.

## Why saves have numbers

catlog never learns what you called your save — the name is hashed on your own
machine before anything is sent, so the server could not tell you even if it
wanted to. Your saves are numbered in the order catlog first saw them: **Save 1**,
**Save 2**, and so on.

That number belongs to your profile. It is a way to recognise your own saves, not
a public identity that can be matched against somebody else's.

## One player can appear more than once

On the ordinary board, your best result across all your saves is your one entry.
On a per-save board, each save ranks on its own, so one player can hold several
rows.

That is the honest answer when the question is about a save. A long-running first
game and a fresh second game did not reach orbit, land or lose vehicles as one
combined career, even though both belong to the same player.

## A save is already a stretch of time

Per-save boards have no daily, weekly, monthly or yearly views. A save already
starts with a new game and continues for as long as you play it; crossing that
with calendar windows would answer a different question from how the save ranks.

If you load an earlier version of a save, catlog marks it as rewound. **The mark
excludes nothing.** The save and all of its qualifying results still rank
normally; the mark only says its clock did not run forwards the whole time.

## Two limits of save identity

- If you delete a save and start a new game with the same name, catlog treats it
  as the same save. The name is what your machine turns into the private identity,
  and the server never receives enough information to distinguish the replacement.
- A game that has never been saved gets a fresh identity each time you start it.
  Save it once if you want later sessions to stay together as one save.

When a newly added board is blank for a short time, the reason is shared by every
kind of board. See [A new board starts empty, not half full](/catlog/leaderboards/eligibility/#a-new-board-starts-empty-not-half-full)
for the one explanation of that rebuild behaviour.
