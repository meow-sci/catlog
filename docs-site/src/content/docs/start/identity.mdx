## The handle is the only public identity

Boards, profiles, comparisons and the activity feed show one thing: the handle you
claimed. There is no display name, no avatar sourced from anywhere, and no second
identifier a determined reader could join on.

A handle is permanent and never recycled. Nobody can take a name you were known by
and be mistaken for you, and that holds after a ban and after a deletion.

## What a ban does

A banned player disappears from every public surface at once, because handles are
resolved from one in-memory directory and a banned player is simply absent from
it. Their rows are still in the derived tables, but nothing can render them.

Two consequences worth knowing:

- **A ban closes the gap rather than leaving a hole.** Ranks are positions among
  the rows you can actually see.
- **An unknown handle, a retired handle and a banned handle all return the same
  "not found".** Deliberately — the alternative is a way to test whether somebody
  was banned.

A ban, a withheld account and a deletion are three different things, and what each
one does to the flights you already flew is on the [privacy
page](/catlog/start/privacy/).

## The career rewind mark

If you load an older save, the game clock goes backwards. catlog notices at the
next session boundary and marks that career as rewound.

**The mark excludes nothing and scores nothing.** It is shown beside a
career-time row so a reader can see that the clock behind it did not run
forwards. It is a label, not a penalty.
